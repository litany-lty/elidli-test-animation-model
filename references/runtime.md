# 开发版范围与正式版门禁

版本 dev-0.3；协议 animation-model-test/dev-0.3。

当前规则：用户说“我要测试模型”触发，先主动收集四项用户素材与可选创作目标，未齐备前不计时。无内置角色/账号。支持文字、图片、网页、社交账号；仅社交账号需头像和近期推文推导。主要复用包保留四项用户要求，用户图片作为核验附件一起交付。

本次开源的是开发版；尚无经过校准的语义与审美评分器，保留正式版门禁。

## 已实现的开发能力

单个 skill，默认固定题面（30 秒 ±1 秒、1280×720、15 分钟作答、2 分钟资料查询）；live-elements/live-brief 及可选冻结比较；收齐素材后发题计时；原始题面指纹；真实事件记录；资料证据接收与迟到标记；资料/设计版本冻结；首次提交保存；用户要求修复时单列尝试与新增耗时；冻结副本隔离浏览器运行；真实画面差分和交互诊断；报告、预览与主要同款复用文本及原有可选存档文本。

没有模型选择、账号、Key、外部评审 API、自动发布、外部模型 CLI 或自动依赖安装。不会改变业务仓库、服务或用户模型配置。

## 支持环境

开发时曾在 macOS arm64、Python 3.14、已有 Playwright、Chromium 和 Pillow 的环境验证浏览器探测；这不代表其他机器已通过。使用前运行 doctor 检查当前环境。

- 记录器：Python 标准库、macOS/Linux 的文件锁、可读启动周期标识；可写本地目录。
- 浏览器诊断：已有 Playwright、其 Chromium、Pillow。未安装时明确降级，不让用户填写配置，也不声称完整零配置运行。
- 资料：宿主已有网页/搜索和图像阅读能力。没有原始证据导出时记录来源准确性未验证。
- Windows、纯聊天客户端、干净机器自动准备流程：未验证；不宣称支持。
- 录像采用 Playwright 原生采集，未校准为协议正式版所需 30 FPS。
- 不随包下载任何模型权重；开发包体积仅脚本与文字。浏览器与 Python 是已有资源，不将其资源成本计为零。

## 评分器研究结论与门禁

[UIClip 官方项目](https://uimodeling.github.io/uiclip/)面向 UI 截图和文字描述；[DOVER 官方仓库](https://github.com/VQAssessment/DOVER)面向用户生成视频质量。两者现有材料都不能证明本题的角色、事件、节奏及五项审美量表已通过验证。因此本版未集成它们，也不输出未经校准的百分分数。未下载代码/权重，未声称完成许可审查。

正式启用自动语义与审美评分前仍须落实：

1. 选定本地语义/审美裁判，核对代码、权重、依赖许可并冻结版本、哈希和推理环境。
2. 至少 40 个代码动画样本，按来源划分校准/保留集；3 名盲评者、至少 100 对比较，验证偏好一致性与误差区间。
3. 单独语义标注和保留集验证；角色、资料、事件顺序及设计兑现覆盖至少 100 项判定。
4. 验证重复稳定性、时序缺陷、提示注入/捷径奖励及弃权；冻结阈值，不追分调参。
5. 固定录像和采样、测试干净环境零手工配置、实测下载/磁盘/内存/耗时。
6. 完整端到端试运行、其余故障试验和兼容环境验收。

不得通过修改状态为 PASS 或接收被测模型手写分数解除门禁；本包没有“导入任意分数”的入口。
